# AI Hallucination Lab

AI 답변의 문맥을 읽고 확인 가능한 사실 정보를 Tavily 검색 근거와 비교합니다. 과학 설명, 추천, 연구·인물 인용, 제품 사양, 통계, 역사 등 여러 형태의 답변을 같은 검증 흐름으로 처리합니다. 모든 문장을 무조건 참/거짓으로 분류하지는 않습니다.

## 기능

- 문맥·대상·사실 유형별 정보 추출 및 Evidence 비교 판정
- 같은 대상을 구분해 존재·귀속·내용·수치·날짜·인과관계 등을 확인
- 의견·감상·질문·예측 등은 사실 판정에서 제외하고 이유 표시
- 출처 제목·도메인·직접 인용·확인 내용·원문 링크 표시 (전체 검색 발췌는 접기)
- TRUE, FALSE, PARTIALLY TRUE, UNCERTAIN 판정 및 보수적 confidence
- 전체 발견 주장, 검증 주장, 미검증 주장과 검증 범위 표시
- 실제 판정된 주장만 사용한 Hallucination Rate 표시
- 검증 우선순위와 답변 전반의 구간별 표본 선택
- API 키는 서버에서만 읽고 브라우저로 전달하지 않음
- 동일 Claim 검색 결과를 10분간 메모리 캐시
- 동일 입력의 검증 결과를 3분간 메모리 캐시 (최대 100건)
- 이 브라우저의 최근 검증 내역 **10건** 저장, 결과 다시 보기, 재검증, 개별/전체 삭제, 자동 저장 끄기

## 실행

Node.js 20.12 이상에서 `outputs` 폴더를 현재 폴더로 두고 실행합니다.

```powershell
npm install
npm start
```

`npm run dev`도 같은 서버를 시작합니다. 저장소를 배포할 때 `package-lock.json`을 함께 사용하고 `npm ci --omit=dev`로 운영 의존성만 설치할 수 있습니다.

브라우저 주소는 `http://localhost:4173`입니다. 다른 포트는 `$env:PORT=4174`를 설정한 뒤 실행합니다. 4173이 이미 사용 중이면 기존 서버를 재사용하라는 안내를 출력합니다.

## API 키 설정

1. [Google AI Studio](https://aistudio.google.com/app/apikey)에서 Gemini 키를 발급합니다.
2. [Tavily](https://app.tavily.com/)에서 Tavily 키를 발급합니다.
3. `.env.example`을 `.env`로 복사하고 키를 입력합니다.

```powershell
Copy-Item .env.example .env
# .env에 GEMINI_API_KEY와 TAVILY_API_KEY를 입력합니다.
npm start
```

`GEMINI_MODEL` 기본값은 `gemini-3.6-flash`이며 환경변수로 변경할 수 있습니다. 키가 없으면 서버는 충돌하지 않고 화면에 `API 키를 설정해주세요.`를 표시합니다.

## 검증 흐름

입력 답변 → Gemini가 문맥과 원문 발췌를 함께 읽어 최대 30개 사실 정보를 발견 → 중복 제거 및 우선순위/구간 분포에 따라 검증 예산 8/10/12개 선택 → 선택한 정보만 Tavily 검색 → Gemini 한 번으로 전체 판정 → 서버가 인용 출처를 검사 → 결과 요약 순서입니다. 일반적으로 Gemini는 2회 호출하며 별도 요약·신뢰도·고급 분석 호출은 없습니다. 사실 정보가 없으면 첫 Gemini 호출 뒤 종료합니다. 각 항목은 원문 발췌, 대상, 사실 유형을 가지며 동일한 자료로 확인 가능한 항목은 검색어를 공유합니다. 관련 없는 항목을 주제가 같다는 이유만으로 같은 검색어에 묶지는 않습니다.

검색하지 않은 항목은 `unverified`, verdict/confidence는 null입니다. `totalClaims`는 발견 수, `verifiedClaims`는 검색·판정을 수행한 수(UNCERTAIN 포함), `verificationCoverage`는 그 비율이며 사실일 확률이 아닙니다. Hallucination Rate는 `FALSE / (TRUE + FALSE + PARTIALLY_TRUE)`로 유지합니다. 분모가 0이면 API의 기존 숫자 0을 유지하되 `rateDenominator: 0`으로 알리고 UI는 계산 불가로 표시합니다.

서버는 모델이 인용한 문구가 해당 검색 발췌에 실제 있는지 확인합니다. TRUE에는 직접 지지 근거, FALSE에는 직접 반박 근거, PARTIALLY_TRUE에는 두 종류의 근거가 모두 필요합니다. 일부 세부 사항이 검색되지 않은 것만으로 PARTIALLY_TRUE나 FALSE를 만들지 않습니다. 동명이인·판본·제품·시점 일치 여부도 판정 프롬프트와 인용 검증에서 확인합니다. 이는 인용의 출처 검사이며 의미 해석의 완전한 정확성을 보장하지는 않습니다.

`verifiedAnswer` 필드는 호환성을 위해 유지하되 TRUE 항목과 근거를 갖춘 수정만 포함합니다. `correctedFacts`에 원래 항목 ID를 연결하고 UNCERTAIN/미검증은 제외합니다. confidence 역시 API에 유지하지만 UI에서는 보정된 확률로 오해하지 않도록 모델 평가로 별도 표시합니다.

Tavily 결과에서 Wikipedia, 위키류, 블로그, 카페 및 주요 커뮤니티 도메인과 하위 도메인은 제거합니다. 검색 결과는 출처 우선순위, Tavily 점수, 본문 관련도를 반영해 정렬하고, 판정 요청에는 Claim당 최대 5개를 전달합니다. Claim 검색 결과는 10분 캐시되고 동일 검색 및 동일 검증의 동시 요청은 in-flight 작업을 공유합니다.

Tavily는 `advanced`, `max_results: 5`, `include_answer: false`, `include_raw_content: false`를 사용합니다. 메뉴·광고가 섞인 전체 원문 대신 검색 본문을 Markdown 토큰으로 정리하고, 중복 URL/본문을 제거합니다. 추가 반례·전문가 검색은 없습니다. 검색 횟수는 선택한 항목 수 이하이며 같은 검색어는 공유합니다. Gemini 추출 실패 시 Tavily를 호출하지 않습니다. 429/500/502/503/504만 최대 3회 Retry-After 또는 지수 backoff+jitter로 재시도합니다. 400/401/403/404는 재시도하지 않습니다. 요청 간 RPM 제한 자체는 API 제공자의 제한을 따릅니다.

## 검증 내역과 저장 범위

- 완료 결과와 입력 원문을 이 브라우저의 IndexedDB에 최대 **10건** 저장합니다. 11번째부터 가장 오래된 내역을 제거합니다.
- `결과 보기`는 저장된 결과만 표시하며 Gemini/Tavily/API 요청을 하지 않습니다. 저장 시점을 보여줍니다.
- `다시 검증`은 기존 API를 다시 요청합니다. 3분 결과 캐시와 10분 검색 캐시는 그대로 적용됩니다.
- 자동 저장 끄기는 앞으로의 저장만 중단합니다. 기존 기록은 개별/전체 삭제로 제거합니다.
- 기기 간 동기화나 서버 영구 저장은 없습니다. 사이트 주소가 달라지면 내역도 별도입니다. 브라우저 데이터 삭제·비공개 모드 종료 시 기록이 사라질 수 있습니다. 업데이트 전에 저장하지 않은 기록은 복원할 수 없습니다.
- 브라우저 저장 실패가 사실 검증 결과 표시를 막지 않습니다. 서버 결과는 3분간, 검색은 10분간 메모리 캐시됩니다. 입력과 검색어는 검증을 위해 각각 외부 Gemini/Tavily 서비스로 전송됩니다.

## 자동 테스트

```powershell
npm install
npm test
```

Node 테스트에서 외부 API를 대체해 호출량·중복 방지·캐시·retry·HTTP 응답·출처 차단·인용 검증·미검증 제외·최근 10건 보관을 확인합니다. 테스트는 실 API 정확도나 계정별 모델 접근 권한을 검증하지 않습니다. 실제 검증은 서버 실행 후 입력란에서 수행합니다. 현재 상태를 모르는 동안 진행률 숫자를 꾸며 표시하지 않습니다.

## 테스트 입력

- 사실: `대한민국의 수도는 서울이다.`
- 오류: `대한민국의 수도는 부산이다.`
- 혼합: `지구는 태양 주위를 돌고, 달은 지구보다 크다.`
- 최신 정보: `현재 한국의 대통령은 누구인가?`
- 확인 어려움: 출처 없는 개인 경험이나 예측

## 프로젝트 구조

```text
outputs/
  index.html   앱 화면
  style.css    반응형 테마와 레이아웃
  app.js       검증 진행 상태와 결과 렌더링
  history.js   브라우저의 최근 10건 저장·조회·삭제
  verification.js  근거 정리·인용 검사·결과 집계
  server.js    정적 파일 서버 및 Tavily/Gemini 검증 API
  test/        외부 API를 호출하지 않는 자동 테스트
```

## 제한사항

- 검색 결과가 모든 주장을 충분히 뒷받침하지 않을 수 있습니다.
- 검색 결과와 판정은 참고용이며, 중요한 정보는 원문 출처를 직접 확인해야 합니다.
- Tavily와 Gemini의 요금, rate limit, 모델 접근 조건은 계정에 따라 달라질 수 있습니다.
