 LIVE API SETUP

실제 검색 검증 설정

API 키는 서버에서만 읽으며 브라우저에 노출하지 않습니다.

  1. outputs/.env.example을 참고해 outputs/.env를 만듭니다.
  2. GEMINI_API_KEY와 TAVILY_API_KEY를 입력합니다.
  3. 서버를 다시 시작한 뒤 검증을 실행합니다.

검색 및 모델 API의 한도와 요금은 계정에 따라 달라질 수 있습니다.
