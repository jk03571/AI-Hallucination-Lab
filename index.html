ABOUT THIS LAB

근거와 함께 읽는 AI 답변

Gemini는 답변 문맥과 사실 정보를 분리하고, Tavily의 검색 근거와 비교합니다. 사실 정보의 종류에 맞춰 대상·수치·귀속·내용을 확인합니다.

검색되지 않는 정보는 거짓이라고 단정하지 않습니다. 의견·개인 경험·예측·코드의 실행 결과 등은 이 서비스의 웹 검색만으로 진위를 확정할 수 없습니다.

검증 결과는 참고용이며, 중요한 결정에는 원문 자료를 직접 확인해 주세요.

 LIVE API SETUP

실제 검색 검증 설정

API 키는 서버에서만 읽으며 브라우저에 노출하지 않습니다.

  1. outputs/.env.example을 참고해 outputs/.env를 만듭니다.
  2. GEMINI_API_KEY와 TAVILY_API_KEY를 입력합니다.
  3. 서버를 다시 시작한 뒤 검증을 실행합니다.

검색 및 모델 API의 한도와 요금은 계정에 따라 달라질 수 있습니다.
